🚀 RTL Design & Synthesis Workshop (Sky130 Edition)

Welcome to the hands-on RTL journey — where you’ll move from coding Verilog to analyzing waveforms, synthesizing hardware, and exploring digital optimization using the Sky130 open-source PDK.

📌 Why Join This Workshop?

This series is tailored for:

🎓 Students aiming to strengthen digital design fundamentals.

🔧 Hobbyists who love experimenting with open-source EDA tools.

💼 Engineers wanting real-world RTL-to-GDSII experience.

By the end, you’ll be comfortable with RTL design, simulation, synthesis, and optimization in an open-source flow.

🛠️ What You’ll Need

Before diving in, make sure you’re set up with:

✅ Basic knowledge of logic gates, flip-flops, muxes

✅ Comfort with Linux command-line basics

✅ A Linux machine (or WSL on Windows/macOS)

✅ Installed tools:

git

iverilog + gtkwave

yosys

Any text editor of your choice

📂 Workshop Roadmap

The workshop spans 5 days, each packed with labs and examples:

Day	Topics	Hands-On Focus
Day 1	RTL Design Basics & Synthesis Flow	First Verilog codes, compile, and simulate
Day 2	Timing Libraries & Flip-Flop Coding Styles	Understand .lib files, coding efficiency
Day 3	Combinational & Sequential Optimizations	Logic minimization and FSM tweaks
Day 4	Gate-Level Simulation & Verilog Nuances	GLS with Yosys netlists, blocking vs non-blocking
Day 5	Synthesis-Driven Optimization	Area, speed, and power-aware RTL tuning

Each folder (Day_1, Day_2, …) contains:
✔ Explanations → ✔ Example Codes → ✔ Screenshots → ✔ Lab Steps

📖 Learning Highlights

🖋️ Write clean Verilog & testbenches

🔍 Simulate & debug with GTKWave

🔧 Synthesize RTL with Yosys + Sky130 libraries

⏱️ Explore timing-driven design flows

📉 Optimize for performance vs. area
